# TT Peluquería

Sistema web de reservas de cortes de pelo y administración para TT Peluquería, Dardo Rocha 626, Rojas, Buenos Aires.

## Alcance

- Reservas por fecha y horario, sin selección de servicios.
- Agenda, clientes, notificaciones, historial y estadísticas.
- Caja con registro de ingresos únicamente al marcar un turno como realizado y cobrado.
- Precio, duración, horarios y bloqueos configurables.
- Next.js, TypeScript y Supabase/PostgreSQL con autenticación y RLS.

## Estado

Proyecto en desarrollo. Aún no está desplegado ni habilitado para recibir reservas reales. El precio y los horarios exactos deben ser configurados por el dueño antes de habilitar reservas.
